radv: keep compute that syncs storage memory at a workgroup barrier in CU mode (RADV_VICTORY_CU_MODE)

For Mesa 26.2.6 (applies with git apply / patch -p1 at the top of a Mesa checkout). See scripts/linux/README.md.

+    * workgroup-scope acquire, so a wave may read another wave's store stale after the barrier.

+   }
